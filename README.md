# Hex iOS — cloud-built IPA

The iOS half of [Hex](https://github.com/anomalyco/hex) (MIT), with a 简体中文 pinyin keyboard
added, plus a GitHub Actions workflow that archives it into an unsigned `.ipa` on a macOS
runner. Nothing here needs a Mac or an Apple Developer account: Sideloadly signs the `.ipa`
with your own Apple ID as it installs.

## What is here

- `ios/` — the app (`HEXMobile`), the keyboard extension (`HEXKeyboard`), the widgets, the
  shared code, and the XcodeGen project. `ios/HEXShared/FullKeyboard/Chinese/` is the pinyin
  keyboard, and `ios/HEXShared/FullKeyboard/Chinese/PinyinDictionary.tsv` its 75k-entry
  dictionary, generated by `ios/scripts/build-chinese-dictionary.py`.
- `app/AppIcon.icon` — Icon Composer's app icon, which `ios/project.yml` reads from `../app`.
- `tests/fixtures/` — the two fixtures `ios/project.yml` pulls in as test resources.
- `.github/workflows/build-ios-ipa.yml` — the build.
- `ios/scripts/build-ipa.sh` — the same build, runnable on any Mac.

## Running it

Actions › **Build iOS IPA** › *Run workflow*. It takes 25–40 minutes: two archives are built,
each resolving FluidAudio, downloading the 25 MB cleanup tagger model, and compiling.

The run leaves one artefact, `hex-ipa`, holding two files:

- `Hex-unsigned.ipa` — the app as the repo ships it, bundle identifiers and App Group intact.
- `Hex-personal.ipa` — the same app with its identifiers rewritten to `com.example.hex` and the
  App Group dropped, because a free Apple ID can neither claim `group.anomaly.hex.mobile` nor
  an identifier the App Store already holds. Try this one when Sideloadly refuses the first.

Pass your own prefix as `personal_prefix` when starting the run, e.g. `com.yourname.hex`, since
`com.example.hex` may itself be taken.

## Installing

On Windows: Sideloadly, iPhone over USB, drag the `.ipa` in, sign in with your Apple ID.
A free account's signature expires after 7 days; a paid one lasts a year.

After installing, allow the keyboard: Settings › General › Keyboard › Keyboards › Add New
Keyboard › Hex, then Settings › General › Keyboard › Keyboards › Hex › Allow Full Access (the
keyboard needs it to hear what you type through the microphone and to keep the pinyin
dictionary warm). 简体中文 is then in the keyboard's language menu: 设置 › 键盘 › 语言.

## Limits

The archive is unsigned, so nothing is verified and no provisioning profile is applied —
that is what makes it buildable without an account. The keyboard extension is inside the app
as built, so an installer that keeps the app's plugins (`Sideloadly` by default does) keeps it.
